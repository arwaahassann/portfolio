# Arwa Hassan — Portfolio

A single-page portfolio site (plain HTML/CSS/JS, no build step needed).

## Run locally
Just open `index.html` in your browser, or serve it:
```
npx serve .
```

## Deploy to Vercel
1. Push this folder to a GitHub repo.
2. Go to https://vercel.com/new and import the repo.
3. Framework preset: **Other** (static site) — no build command needed, output directory is `.`
4. Click Deploy.

Or deploy instantly without GitHub using the Vercel CLI:
```
npm i -g vercel
vercel
```
